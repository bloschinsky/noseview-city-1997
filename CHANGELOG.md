# Changelog

Notable changes to the canonical NOSEVIEW 1997 edition are recorded here.

## 1.13.0 — 2026-07-29

### Added

- A first-screen live-play link and current default-state media.
- Separate Free Flight and Signal Hunt instructions.
- Clear local-run, browser-support, architecture, credits, licensing, and
  release-history documentation.

### Changed

- Reorganized the repository presentation so visitors see and can launch the
  game before reading implementation details.

## 1.12.0 — 2026-07-29

### Changed

- Smoothed acceleration, deceleration, yaw, and pitch while preserving precise
  collision resolution and deterministic reset behavior.

## 1.11.4 — 2026-07-29

### Added

- A Missions directory for selecting, starting, replaying, and aborting the
  implemented Signal Hunt assignment.

## 1.11.2 — 2026-07-29

### Added

- Optional Fuel Endurance with deterministic pickups and shared accessible Game
  Over handling.

## 1.10.1 — 2026-07-29

### Added

- Optional Hull Integrity with normalized collision damage and accessible restart
  handling.

## 1.9.2 — 2026-07-29

### Added

- Normalized collision incident records covering buildings, landmarks, rooftops,
  and ground contact.

## 1.9.1 — 2026-07-29

### Added

- An optional deterministic WebGL starfield, mutually exclusive with Digital
  Rain and disabled by default.

## 1.7.0 — 2026-07-22

### Added

- The deterministic timed Signal Hunt game mode with rooftop transmitters,
  two-second target acquisition, mission telemetry, and completion flow.

## 1.5.0 — 2026-07-22

### Added

- Three synchronized procedural landmarks in every city.
- Ground protection, radial navigation warnings, signal degradation, countdown
  cues, and automatic recovery.

## 1.3.4 — 2026-07-22

- Preserved and tagged the known-good modularization baseline.
